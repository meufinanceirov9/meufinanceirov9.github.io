# Como atualizar o app na Netlify

1. Extraia o ZIP da v13.07.
2. Entre no painel da Netlify usado pelo Financeiro CRM.
3. Abra o site que mantém o endereço atual do app.
4. Faça um novo deploy enviando a pasta extraída inteira, com `index.html` na raiz.
5. Aguarde a publicação e abra o endereço acrescentando `?v=1307` na primeira visita.
6. No Perfil, confirme que aparece `v13.07`.

Não crie outro site se quiser conservar o mesmo endereço. Atualize o deploy do site atual.
